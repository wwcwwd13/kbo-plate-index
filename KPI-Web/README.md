# KBO Plate Index

KBO Plate Index(KPI) 웹페이지의 첫 화면입니다.

현재는 React나 Vite 없이 HTML·CSS·JavaScript로 시작한 화면 골격입니다.

## 현재 화면

- 1군/2군 선택
- 구단별 KPI 표 영역
- 선택 구단의 시간 흐름 그래프 영역
- 최신 기준일·리그 평균·선택 구단 요약 카드

## 데이터 연결

`data/team_ratings.json`을 읽어 표와 그래프를 표시하도록 구성되어 있습니다.

현재 파일은 빈 초기 데이터이며, 다음 단계에서 최신 구단별 Rating 결과를 연결합니다. 원자료와 v3 계산 결과는 이 화면 코드와 분리해서 보관합니다.

## 방향

초기 목표는 외부 사용자에게 타석 전체 로그를 보여주는 것이 아니라, 구단별 KPI를 직관적으로 보여주는 것입니다. 타석 단위 before/after와 내부 변수는 검증용 원자료로 유지하고 기본 화면에는 노출하지 않습니다.
